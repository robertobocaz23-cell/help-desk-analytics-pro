# Help Desk Analytics Pro

Dashboard interactivo para monitorear y analizar tickets de mesa de ayuda.

## Características

- Carga de archivos CSV con datos de tickets
- KPIs en tiempo real (total, cerrados, abiertos, tiempo promedio)
- Gráficos interactivos (Chart.js)
- Filtros por fecha y por agente
- Informe ejecutivo mensual automatizado
- Exportación a Excel y PDF
- Modo oscuro
- Logo corporativo personalizable

## Cómo usar

1. Abre el archivo `dashboard.html` en tu navegador
2. Haz clic en "Subir CSV" y selecciona tu archivo
3. Filtra, analiza y exporta

## Tecnologías utilizadas

| Tecnología | Propósito |
|------------|-----------|
| HTML5 | Estructura |
| CSS3 | Estilos visuales |
| JavaScript (ES6+) | Lógica de la aplicación |
| Chart.js | Gráficos estadísticos |
| SheetJS | Exportar a Excel |
